# 生成前 / 生成后的双阶段审核清单

## A. Content Lock（生成前）

- [ ] 正确解析主题数量、顺序、比较式单主题和合图要求；合图涉及的主题均已达到 `READY`。
- [ ] 比例、语言、方向、装饰参数已写入 Visual Brief；用户设置优先，未指定项采用默认值，比例与方向一致。
- [ ] 每个主题有可访问的可靠资料或关联对话，不依赖模型自带常识。
- [ ] 每条拟出现的技术断言有对应来源；历史助手说法已与可用材料核对。
- [ ] 公式、形状、上下标、变量说明已锁定；数值及年份不靠猜测。
- [ ] 示例数值标为“示意”，原文实验结果与自造展示严格区分。
- [ ] 视觉参考图只用于视觉，不被当作当前知识来源。
- [ ] 关键关系（流程/对比/因果/结构）足以绘制具有教学意义的图。
- [ ] 文案短，模块数量服务知识而非凑版面。

关键事实不可核实则该主题为 `NEEDS_CONTEXT`，先补充。

## B. Visual & Factual QA（生成后）

- [ ] 比例、语言、方向、装饰符合 Visual Brief；默认每主题一张，明确要求合图时交付一张综合图，图片数量与已完成出图单位一致。
- [ ] 视觉语言符合三张样图：色彩、圆角蓝框、标题、图标、留白。
- [ ] 关键公式逐符号匹配锁定内容（重点查求和边界、转置、希腊字母）。
- [ ] Expert/Token/Head、Top-K、维度、版本、总量没有错写。
- [ ] 箭头、流程阶段、因果顺序没有反转。
- [ ] 不添加虚构统计图、实验结论或“论文证明”字样。
- [ ] 标注“示意 / 推导 / 来源”时内容与来源类型一致。
- [ ] 文字可读，未裁边，装饰不遮挡正文。

无法修正的重大事实错误要明确告知，不得把图宣称为已通过事实审核。
