# Context Note Illustrator

**对话上下文驱动的学习笔记插画 Skill**  

把用户已经讨论过的课程内容、讲义、论文片段和笔记，整理为结构化的**手绘课程笔记插画**；默认每个独立主题一张，用户明确要求合图时遵照执行。

## 1. 核心能力

| 能力 | 默认行为 |
|---|---|
| 对话上下文提取 | 使用当前**可访问**聊天与附件 |
| 严格知识边界 | 未获授权，不联网、不用内部常识补造技术知识 |
| 单主题 | 每个主题一张图片 |
| 多主题 | 解析编号列表，逐主题检查，默认分别生成；明确要求合图时生成一张综合图 |
| 信息不充分 | 不生成该主题，指出具体缺失项，要求资料或进一步讨论 |
| 风格统一 | 内置用户选择的三张参考图，仅沿用视觉风格 |
| 公式与图表 | 出图前锁定，出图后核对公式、维度、箭头和数值 |
| 默认格式 | 竖版 3:4、简体中文、专业英文术语保留 |

## 2. 快速使用

最推荐直接复制：

```text
帮我生成一张笔记插画, 主题:
1. 稀疏路由与负载均衡
2. Expert Parallelism
3. DeepSeek MoE V1–V3
```

**预期：三张独立笔记插画。** 用户说“一张”但列出编号主题时，以“每个主题一张”为默认解释。全部主题使用同样的风格规范。

单主题：

```text
帮我生成一张笔记插画，主题：Gated DeltaNet 的状态更新。只使用我们上面讨论过的公式。
```

版本对比（视为**一个**整体主题）：

```text
帮我生成一张笔记插画，主题：DeepSeek MoE V1–V3 的架构演进。
```

显式请求单张综合图：

```text
请把上面的 3 个概念合成一张对比笔记图，比例 3:4。
```

### 也可自定义

- 画幅：`比例 16:9`、`比例 3:4`。
- 语言：`使用英文`、`使用简体中文`。
- 内容范围：`只根据 Lecture P40–P43`、`不画实验数据`。
- 细节层级：`侧重公式推导`、`侧重系统流程`、`面向初学者`。
- 对图像的额外限制：`不要人物装饰`、`每张最多 4 个知识模块`。

**用户明确指示优先于默认值；未经用户授权，不能放宽严格上下文规则。**

未指定时，使用 **3:4 竖版、简体中文（保留专业英文术语）、少量学习装饰**。指定其他比例时，横竖方向随比例调整；指定语言或装饰要求时同步应用。明确要求合图时，需先确认所有拟合入主题的内容充分。
